# Security review

1. 识别每个入口的身份来源、权限判断和资源归属校验。
2. 检查查询、模板、序列化、HTML、Shell 和 URL 边界是否使用安全 API。
3. 上传文件限制大小、类型、名称、存储位置和下载权限；不要信任客户端 MIME。
4. 日志只记录排障所需摘要，令牌、口令、个人数据和完整请求体默认脱敏。
5. 以攻击路径和修复证据报告问题，区分已验证、推断和待人工确认项。

## 常见门禁

- Token 校验不仅确认签名和过期时间，还要检查受众、发行者、撤销/轮换策略和最小作用域。
- 对象级授权必须验证当前主体能否访问目标对象，不能只依赖前端隐藏按钮或可猜的 ID。
- 动态排序、过滤、模板和命令参数使用白名单或参数化 API；输出到 HTML、日志和 CSV 时分别编码。
- 上传下载隔离存储与执行路径，下载再次检查授权；请求和响应设置大小、频率、超时与并发上限。
- 安全日志记录谁、何时、对什么资源做了什么和结果；不记录秘密，告警内容也遵循同一脱敏规则。
